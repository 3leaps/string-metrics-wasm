# string-metrics-wasm v0.3.10 Release Notes

**Release Date**: 2026-06-15 **Status**: Release-process hardening — signed tags, release checklist,
and signed artifacts

v0.3.10 is a **release-process** release. It establishes signed release tags, an authoritative
release checklist, signed release artifacts, and a hardened CI release job. There are **no library
code, public API, runtime, or fixture changes** — the published package is functionally identical to
v0.3.9 (the only packaged change is `docs/publishing.md`). Consumers do not need to upgrade for
functionality; this release exists to make the project's releases verifiable and repeatable.

## Signed Release Tags

Release tags are now **GPG-signed** (`git tag -s`) with the 3 Leaps signing key and verified
(`git verify-tag`) before pushing. v0.3.10 is the first release cut under this process.

## Release Checklist

A new `RELEASE_CHECKLIST.md` is now the authoritative, checkbox release procedure — prerequisites →
dry-run verification → signed tag → publish → sign artifacts → post-release verification. It is
adapted from the fulmenhq/tsfulmen library release pattern and uses 3 Leaps key materials.
`docs/publishing.md` and `AGENTS.md` were updated to match and cross-reference it.

## Signed Release Artifacts

Released tarball checksums (`SHA256SUMS` / `SHA512SUMS`) are signed with the 3 Leaps **minisign**
key and attached to the GitHub Release, so the distributed artifact can be verified independently of
npm.

## Hardened CI Release Job

The tag-triggered release job now guards that the tag matches `package.json`, requires the
per-version release notes (`docs/releases/vX.Y.Z.md`), fails on a missing tarball, and uses those
notes as the GitHub Release body.

> Full OIDC trusted publishing and CI-side artifact signing are intentionally deferred to a later
> (v0.4.x) hardening pass; v0.3.10 keeps npm publishing manual.

## Compatibility

- No public API, runtime, metric, or fixture changes — drop-in from v0.3.9.
- Multi-runtime support (Node.js, Bun, Deno) and the embedded-WASM packaging from v0.3.9 are
  unchanged.
