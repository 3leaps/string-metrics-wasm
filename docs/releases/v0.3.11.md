# string-metrics-wasm v0.3.11 Release Notes

**Release Date**: 2026-06-16 **Status**: Standardized release Make targets

v0.3.11 is a **release-tooling** release. It adds the standard 3 Leaps library `make release-*`
targets so the signed-tag and artifact-signing steps are run as named Make targets rather than raw
commands. There are **no library code, public API, runtime, or fixture changes** — the published
package is functionally identical to v0.3.10.

## Standardized Release Targets

New Make targets (thin wrappers over `scripts/release-*.sh`), matching the pattern used across the 3
Leaps libraries:

- `make release-check` — validate release readiness (quality + tests)
- `make release-guard-tag-version` — guard that the git tag matches the `package.json` version
- `make release-tag` — create and verify a **GPG-signed** tag (guards: clean tree, on `main`,
  semver, tag not already present)
- `make release-verify-tag` — verify the signed tag
- `make release-sign` — download the released tarball, generate `SHA256SUMS`/`SHA512SUMS`,
  **minisign** them, and upload them to the GitHub Release

The release tag is derived from `package.json` (`vX.Y.Z`); signing keys are referenced by
environment-variable name only (configured out-of-band). `RELEASE_CHECKLIST.md` and
`docs/publishing.md` now drive the signed tag and artifact signing through these targets.

## Compatibility

- No public API, runtime, metric, or fixture changes — drop-in from v0.3.10.
